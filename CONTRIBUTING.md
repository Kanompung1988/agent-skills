# Contributing to the AREAZERO Skill Lab portfolio

This is a directory, not the source tree for released Agent Skills. For code fixes or capability changes, contribute directly to the relevant public repository:

- [OpenAPI Compatibility Audit](https://github.com/Kanompung1988/openapi-compat-audit)
- [CI Log Triage](https://github.com/Kanompung1988/ci-log-triage)

For a new skill idea, submit an issue to this portfolio with the problem, why existing tools are insufficient, reproducible example and expected safety boundaries. A release needs its own public repo, tests and documentation, not a new `skills/<name>` folder on this default branch.

Never upload secrets, private logs or proprietary specifications in issues or PRs.
