# Contributing

Open an issue with a redacted, **synthetic** minimal YAML reproduction and observed/expected results. Do not include API tokens, credentials, private artifact links or sensitive workflow content. Run `python -m unittest discover -s tests -v`, the safe/review fixtures and metadata validation before requesting review. Every behavior change needs regression tests and updated limits documentation. PR CI on Python 3.10 and 3.12 must pass. The original Area Zero SVG is not MIT-licensed and should remain byte-identical. No social post scheduling is part of this repository.
