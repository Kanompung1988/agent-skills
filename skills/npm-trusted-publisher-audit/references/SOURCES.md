# Verified primary sources (2026-11-14)

- [npm Trusted Publishing](https://docs.npmjs.com/trusted-publishers/) — current providers, GitHub OIDC requirements, reusable workflow caller identity, cloud-runner caveats, automatic provenance and token fallback.
- [npm provenance](https://docs.npmjs.com/generating-provenance-statements/) — restrictions and attestations.
- [GitHub Actions permissions](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#permissions) — effective permission scoping.

A local publisher inventory is only an asserted configuration. The script does not call npm APIs or prove the live trusted publisher matches that inventory.
